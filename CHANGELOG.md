# Changelog

## 0.1.1 — 2026-10-09

### Added

- Openwide branding and transparent extension icons.
- Shared charcoal and dark-green styling for the popup and player panel.
- Illustrated seven-mode selector with keyboard navigation.
- Editable numeric values, individual resets, inline validation, and conditional effect controls.
- Effective-mode and crop-loss summaries with separate technical diagnostics.
- Legacy settings retention, UI, fallback, and viewport regression tests.

### Changed

- Grouped advanced controls into Picture, Effects, Site settings, and Diagnostics.
- Positioned the player panel at the viewport's upper right with bounded scrolling.
- Renamed exports to `openwide-settings.json`.
- Kept native YouTube control-bar alignment and removed the floating launcher.

### Compatibility

- Preserved the existing settings schema, storage key, shortcuts, and permission model.
- Native fitting, padding detection, and rendering behavior remain unchanged by the UI refresh.
- Preview compatibility is documented in [the capability matrix](docs/COMPATIBILITY.md).
