# Security

Version 0.1.1 is the current preview release. Security reports should use the latest published build and include a minimal reproduction when possible.

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/sudoaanish/Openwide/security/advisories/new). Do not disclose credentials, access tokens, private media URLs, or exploitable details in a public issue. If private reporting is unavailable, contact the maintainer through the contact information linked from the [GitHub profile](https://github.com/sudoaanish).

Relevant boundaries include optional host permissions, content-frame message authorization, settings import validation, extension-local data, and restoration after permission revocation. Playback compatibility defects without a security impact belong in the issue tracker.
