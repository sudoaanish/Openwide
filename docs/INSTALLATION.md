# Installation and troubleshooting

## Install a release

1. Download `openwide-0.1.1.zip` from [GitHub Releases](https://github.com/sudoaanish/Openwide/releases).
2. Extract the archive to a permanent folder. Its root contains `manifest.json`.
3. Open `chrome://extensions` or `edge://extensions`.
4. Enable Developer mode, click Load unpacked, and select that folder.
5. Visit a video page, open the Openwide popup, and click Enable on this site.

The source ZIP generated by GitHub is different from the packaged extension ZIP. Source needs `npm ci` and `npm run build`; load the resulting `dist` folder.

## Choose a mode

| Mode     | Behavior                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------- |
| Auto     | Remove confident padding; Fill within the crop budget, otherwise Fit with ambience when available |
| Original | Restore the player's original presentation                                                        |
| Fit      | Preserve the active picture's proportions inside the player                                       |
| Fill     | Zoom the active picture to cover the player; the panel shows estimated picture loss               |
| Stretch  | Scale the picture uniformly along each axis to fill the player                                    |
| Elastic  | Protect the center while expanding the edges; limited expansion can leave ambient space           |
| Ambient  | Preserve the picture and fill unused space with blurred video colors                              |

Auto never selects Elastic. Border removal can trim logos or text printed inside encoded bars even when it preserves the film's underlying scene. Use manual borders or detection lock to control this behavior.

## Update

Back up settings using Export settings in the popup. Extract the new release into the same installation directory, reload the existing extension card, and reload open video tabs. Do not remove the existing extension to perform a normal update.

## Troubleshooting

**No video appears in the popup.** Enable the site and start playback. For a cross-origin embedded player, grant the embedded origin in Settings and permissions. Select the appropriate player frame when more than one is available.

**The panel is not visible.** Use Alt+Shift+U, Open player controls in the popup, or the Openwide settings button in YouTube's control bar. Check browser shortcut assignments if another application uses the same keys.

**The picture moves as border text changes.** Open Picture, adjust the manual borders, or lock detection. Manual border changes override automatic detection for the current video.

**Ambience or Elastic is unavailable.** Protected video and cross-origin restrictions can block pixel access. Use native Fit or Fill with manual borders. Open Diagnostics for the reported capability and fallback.

**Ambience disappears in fullscreen.** Some players fullscreen only the video element, which cannot contain sibling effect layers. Use Fullscreen in Openwide's player panel when the player shell supports it.

**Zoom crops too much.** Choose Fit or Ambient. Auto uses a 2% crop budget by default; adjust it in Picture. Reset Zoom to remove additional user zoom.

**Another fitting extension is enabled.** Disable its fitting effect while comparing modes. Openwide restores owned video styles when disabled, but two extensions applying geometry at the same time can produce conflicting results.

**Video performance decreases.** Reduce ambient quality, blur, or FPS in Effects. WebGL Elastic renders a separate foreground surface; switch to Fit, Fill, or Ambient to retain native foreground rendering.

## Reporting a problem

Include the browser and extension versions, player, requested mode, monitor resolution, reproduction steps, and relevant Diagnostics text. Use generated fixtures when possible. Redact account information, private server addresses, and tokens from screenshots and reports.
