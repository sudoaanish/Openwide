# Openwide 0.1.1

An early preview of Openwide for Chrome and Edge on Windows, with native video fitting, black-padding detection, center-preserving Elastic Stretch, and fullscreen ambience.

## Highlights

- Charcoal/green popup and player controls with Openwide branding.
- Seven modes, mode-specific effect controls, editable values, and individual resets.
- Native YouTube buttons for Fill, Elastic, and the full panel.
- Local site profiles, configurable shortcuts, and settings import/export.

## Download and install

Download `openwide-0.1.1.zip`, extract it, enable Developer mode at `chrome://extensions` or `edge://extensions`, and choose Load unpacked. Select the extracted folder containing `manifest.json`, then enable the video site through the popup.

`SHA256SUMS.txt` contains the archive checksum. Node.js is not required for the packaged extension. GitHub's source archives require a build before installation.

## Compatibility

Live Chrome YouTube fitting, detection, ambience, and WebGL Elastic are verified. Other player adapters are included with runtime capability checks; service-level validation is incomplete. Protected playback uses native fitting and manual adjustments where permitted. Pixel effects require readable frames. SVG Elastic is experimental.

Validation includes 40 unit tests, 20 Chrome/Chromium checks, 19 Edge checks, typecheck, and a production build. RTX VSR activity and sustained GPU performance require testing on the target device.

When updating, reload the same installed extension to retain profiles and shortcut assignments. See [installation](https://github.com/sudoaanish/Openwide/blob/main/docs/INSTALLATION.md) and [compatibility](https://github.com/sudoaanish/Openwide/blob/main/docs/COMPATIBILITY.md).
